# Conditions validation status

This ledger separates checks that can be completed from repository data from
scientific validation that requires independent observations. A schema check,
complete archive, or calculated score is not by itself evidence that a model is
accurate.

For the project-wide, dataset-by-dataset requirements—including terrain,
buildings, canopy, weather, CFD wind, thermal, sunlight, runoff, traffic,
walking/transit and pollutant layers—see the [exact data validation
checklist](DATA_VALIDATION_CHECKLIST.md).

## Minimum checks for every incoming observation file

Before scoring, retain the original file and check: required columns; numeric
units and plausible ranges; timezone-aware timestamps; duplicate/missing rows;
sensor identifiers, calibration and quality flags; averaging period; sensor
height; coordinate reference system and transformation; location inside the
relevant model domain; and one predeclared calibration/holdout assignment.
Exclude a row only with a recorded reason. Keep excluded counts and coverage
with the report.

For time-series comparisons, pair data only when location, height, variable,
averaging window and forcing conditions are comparable. Report n, temporal and
spatial coverage, bias, MAE, RMSE, directional error where relevant, and
holdout results separately. Set acceptance limits before inspecting holdout
scores. Do not promote a model from an in-sample fit or one aggregate score.

## Data classes still requiring separate evidence

- Terrain, buildings, roofs and canopy need independent survey/LiDAR checks,
  source dates, CRS/vertical datum, stable IDs and mapped-coverage accounting.
- Sun/shade needs observed shadow timing/extent checks; cumulative energy needs
  radiation observations and a separate method check.
- Traffic needs observed counts, speeds, queues or travel times in matched
  periods; synthetic stability sweeps do not calibrate real demand.
- Walking links and accessibility need field checks of access, barriers,
  crossings, surfaces and grades. Schedules need current operator timetables or
  observed arrivals.
- Runoff needs rainfall, drainage connectivity/capacity, infiltration evidence
  and observed ponding or authoritative flood-study comparisons.
